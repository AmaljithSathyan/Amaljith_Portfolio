# Amaljith_Portfolio

Futuristic UI/UX designer portfolio built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

Import this repository into Vercel as a Vite project.

- Build command: `npm run build`
- Output directory: `dist`
- Root deployment path: `/`

No extra environment variables are required for the default Vercel deployment.
